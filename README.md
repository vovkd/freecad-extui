# Extui аддон

Добавляет во Freecad возможность создавать и настраивать overlay панель в области моделирования деталей.

## Как пользоваться?

### Установка
1. Клонируйте репозиторий в папку с аддонами вашей установки фрикад

Например, на Mac-е это можно сделать так:
```
git clone git@github.com:vovkd/freecad-extui.git /Users/$USER/Application Support/FreeCAD/v1-2/Mod/ExUI/
```
2. [Качайте zip-архив](https://github.com/vovkd/freecad-extui/archive/refs/heads/main.zip) и распаковывайте его в папку с аддонами вашей установки Фрикада

### Работа с аддоном
После установки в самом верхнем меню, где расположены пункты "Файл", "Редактирование" и т.д., в самом конце появится пункт меню Ext UI.
Жмите его и настраивайте. Можно настроить панель под каждый верстак. Все настройки сохраняются в стандартном конфиге фрикада. 

<img width="800" alt="image" src="https://github.com/user-attachments/assets/b6f1f726-7a2f-40e3-b4a9-3ee9c5b558d6" />


Инструменты на панели можно группировать. Для этого просто перетащите мышкой один инструмент поверх другого и он автоматически станет дочерним. 
На панели такой инструмент будет отображаться в выпадающем списке, если нажать на область рядом со стрелочккой
